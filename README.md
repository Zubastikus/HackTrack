# HackTrack

**HackTrack** — веб-система для организации и проведения хакатонов.

Проект предназначен для того, чтобы заменить разрозненные таблицы и документы единой системой управления участниками, командами, направлениями и расписанием мероприятия.

## Технологии

### Backend

* **NestJS**
* **TypeScript**
* **TypeORM**
* **MySQL**
* **JWT**
* **Telegram Bot API**

### Frontend

* **React**
* **Tailwind CSS**
